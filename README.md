# AFT.SBTVC Static Website

เว็บไซต์เวอร์ชัน Static ไม่มี Database ใช้ HTML/CSS/JavaScript ธรรมดา

## สำคัญ
ไฟล์ชุดนี้อ้างอิงโลโก้เดิมที่ `assets/aft_seal.png` จาก Repository ปัจจุบัน ดังนั้นตอนนำไฟล์ชุดนี้ไปวาง ให้เก็บไฟล์โลโก้เดิมไว้

## เปิดดู
เปิด `index.html` โดยตรง หรือใช้ VS Code Live Server

## โครงสร้าง
- index.html
- news.html
- activities.html
- committee.html
- documents.html
- about.html
- contact.html
- 404.html
- css/style.css
- js/main.js

## ก่อนเผยแพร่จริง
ตรวจสอบรายชื่อคณะกรรมการ ประวัติอย่างเป็นทางการ ข่าว กำหนดการ และไฟล์เอกสารฉบับจริงอีกครั้ง
